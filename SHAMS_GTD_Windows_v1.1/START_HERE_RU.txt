SHAMS GTD — WINDOWS

1. Распакуй архив в отдельную папку.
2. Установи Node.js (версия 20 или новее), если он ещё не установлен.
3. Открой эту папку в терминале.
4. Выполни: npm install
5. Для запуска тестовой версии: npm start
6. Для создания установщика .exe на Windows: npm run dist:win

Установщик будет в папке release.

ВАЖНО: это исходный проект настольной версии, а не готовый .exe. Для сборки нужны Node.js, интернет на время установки зависимостей и Windows-компьютер. Задачи пока сохраняются локально; облачной синхронизации и аккаунтов ещё нет.

Можно проще: запусти run_app.bat для теста или build_installer.bat для сборки .exe.
