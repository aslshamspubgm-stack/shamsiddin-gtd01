# SHAMS GTD для Windows — исходный проект v1.0

Это настольная оболочка Electron для интерфейса SHAMS GTD. Приложение открывается в отдельном окне Windows и использует локальное хранилище приложения для задач и настроек.

## Что уже есть
- отдельное окно Windows, минимальный размер 900×620;
- интерфейс на русском, английском и узбекском;
- светлая и тёмная темы;
- GTD-разделы: обзор, Inbox, Next Actions, Projects, Waiting For, Someday / Maybe, Completed;
- локальное сохранение задач и настроек;
- конфигурация установщика Windows `.exe` с ярлыками на рабочем столе и в меню «Пуск».

## Как запустить проект для проверки
Нужны Node.js 20+ и интернет для первой установки зависимостей.

```bash
npm install
npm start
```

## Как собрать установщик Windows
Лучше выполнять эти команды на компьютере с Windows:

```bash
npm install
npm run dist:win
```

Готовый установщик появится в папке `release/`.

## Важно — честный статус
В этом архиве подготовлен проект Windows-приложения и конфигурация сборки. Сам `.exe` здесь не приложен: для его создания нужно установить Electron-зависимости и выполнить сборку на Windows. В этой версии данные хранятся локально на этом компьютере. Нет регистрации, облачной синхронизации, сервера, базы PostgreSQL или оплаты. Не удаляй папку пользовательских данных приложения, если хочешь сохранить локальные задачи.

## Технологии и безопасность
Electron с `contextIsolation`, `sandbox` и отключённым `nodeIntegration`. Внешние HTTP/HTTPS-ссылки открываются системным браузером, а не внутри окна приложения.

## Быстрые BAT-файлы
- `run_app.bat` — установить зависимости (если нужно) и открыть приложение для теста.
- `build_installer.bat` — собрать Windows `.exe`-установщик автоматически.
